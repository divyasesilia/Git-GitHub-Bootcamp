# GitHub Overview

## Introduction

GitHub is a cloud-based platform that provides hosting for Git repositories and enables developers, analysts, and teams to collaborate on projects.

It extends Git functionality by providing tools for repository management, collaboration, code review, project tracking, and automation.

GitHub is widely used across software development, data analytics, machine learning, and open-source communities.

---

# What is GitHub?

GitHub is an online platform built around Git that allows users to:

- Store repositories online
- Share projects publicly or privately
- Collaborate with teams
- Review code changes
- Manage project tasks
- Automate workflows

Git manages version history locally, while GitHub provides a remote platform for sharing and collaboration.

---

# Git vs GitHub

| Git | GitHub |
|---|---|
| Version control system | Cloud-based repository hosting platform |
| Installed on local machine | Accessed through web |
| Tracks file changes | Stores and manages Git repositories |
| Works offline | Requires internet for remote operations |
| Command-line tool | Collaboration platform |

# Why GitHub is Used

## 1. Repository Hosting

GitHub stores project repositories online.

Example:

```
Data-Analysis-Project

├── SQL Queries
├── Python Notebooks
├── Reports
└── Documentation
```

A project can be accessed from anywhere.

---

## 2. Collaboration

Multiple people can work on the same project.

GitHub provides:

- Branches
- Pull Requests
- Code Reviews
- Discussions

---

## 3. Project Portfolio

GitHub acts as a professional portfolio for technical professionals.

A strong GitHub profile can showcase:

- Projects
- Coding skills
- Documentation ability
- Problem-solving approach

---

## 4. Open Source Contribution

GitHub allows developers to contribute to public projects.

Common activities:

- Reporting issues
- Improving documentation
- Submitting changes
- Reviewing code

# GitHub Repository

A repository (repo) is a storage location for a project.

A GitHub repository contains:

- Project files
- Commit history
- Branches
- Documentation
- Collaboration settings

Example:

```
Git-GitHub-Bootcamp

├── README.md
├── 01-Git-Basics
├── 02-GitHub-Basics
└── Projects
```

---

# Interview Questions

## 1. What is GitHub?

GitHub is a cloud-based platform that hosts Git repositories and provides collaboration features.

---

## 2. What is the difference between Git and GitHub?

Git is a version control system, while GitHub is a platform for hosting and collaborating on Git repositories.

---

## 3. What is a GitHub repository?

A GitHub repository is an online storage location containing project files and their version history.

---

## 4. What is the purpose of README.md?

README.md explains the project purpose, structure, setup instructions, and usage details.
