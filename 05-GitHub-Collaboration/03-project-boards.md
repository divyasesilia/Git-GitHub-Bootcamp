# GitHub Project Boards

## Overview

GitHub Projects are tools used to organize and manage work inside a repository.

They provide a visual way to track tasks, issues, and development progress.

GitHub Projects are based on project management concepts such as:

- Kanban boards
- Task tracking
- Sprint planning
- Workflow management

---

# What is a GitHub Project Board?

A GitHub Project Board is a visual workspace where tasks are organized into different stages.

Example:

```
Project Board

Todo          In Progress        Review        Done

Task 1        Task 3             Task 5        Task 7
Task 2        Task 4                            Task 8
```

It helps teams understand:

- What needs to be done
- What is currently being worked on
- What has been completed

---

# Why Use GitHub Projects?

GitHub Projects help teams:

- Organize tasks
- Track progress
- Manage releases
- Prioritize work
- Improve collaboration

---

# GitHub Project vs GitHub Issues

| GitHub Projects | GitHub Issues |
|---|---|
| Organizes work visually | Tracks individual tasks |
| Shows project progress | Describes problems or requests |
| Uses boards and views | Uses discussions and tracking |
| Manages multiple tasks | Focuses on one task |

Projects often use Issues as the tasks displayed on the board.

---

# Kanban Board Concept

A Kanban board represents workflow stages.

Common columns:

```
Todo

↓

In Progress

↓

Review

↓

Done
```

---

# Common Project Columns

## Todo

Contains planned tasks.

Examples:

```
Add SQL analysis
Create dashboard design
Update documentation
```

---

## In Progress

Tasks currently being worked on.

Examples:

```
Cleaning dataset
Building charts
Writing queries
```

---

## Review

Tasks waiting for checking.

Examples:

```
Review SQL queries
Check dashboard calculations
Validate documentation
```

---

## Done

Completed tasks.

Examples:

```
Dataset cleaned
Dashboard completed
README updated
```

---

# Creating a GitHub Project

Steps:

1. Open GitHub repository
2. Select Projects
3. Click New Project
4. Choose Board template
5. Add columns
6. Add Issues or tasks

---

# Adding Issues to a Project

Existing issues can be added to a project board.

Example:

Issue:

```
#25 Add customer analysis
```

Board:

```
Todo

↓ 

In Progress

↓

Done
```

The issue moves through the workflow.

# Project Views

GitHub Projects support different views.

Common views:

## Board View

Visual Kanban workflow.

Example:

```
Todo | Doing | Done
```

---

## Table View

Spreadsheet-style tracking.

Example:

| Task | Status | Owner |
|---|---|---|
| SQL Analysis | Done | Analyst |
| Dashboard | Review | Analyst |

---

## Roadmap View

Used for planning future work.

Example:

```
July:
Data Cleaning

August:
Dashboard

September:
Deployment
```

# Automation in Projects

GitHub Projects can automate workflows.

Examples:

When an issue is created:

```
New Issue

↓

Automatically added to Todo
```

When a Pull Request is merged:

```
PR Merged

↓

Move task to Done
```

# Best Practices

## Keep Tasks Small

Good:

```
Create monthly sales chart
```

Avoid:

```
Complete entire project
```

---

## Update Status Regularly

Move tasks as work progresses.

---

## Link Issues and Pull Requests

Maintain clear project history.

---

## Use Clear Task Names

Good:

```
Fix profit calculation query
```

Avoid:

```
Fix issue
```

# Interview Questions

## 1. What are GitHub Projects?

GitHub Projects are tools used to organize and track work using visual boards.

---

## 2. Difference between GitHub Issues and Projects?

Issues track individual tasks, while Projects organize multiple tasks into workflows.

---

## 3. What is a Kanban board?

A Kanban board visually represents tasks moving through workflow stages.

---

## 4. How do GitHub Projects help teams?

They improve planning, visibility, collaboration, and task management.
